AWSTransformNetworkMigrationAgentPolicy

Description: Grants permissions for AWS Transform to deploy and configure network infrastructure including VPCs, Transit Gateways, and route tables for network migration

AWSTransformNetworkMigrationAgentPolicy is an AWS managed policy.

Using this policy

You can attach AWSTransformNetworkMigrationAgentPolicy to your users, groups, and roles.

Policy details

  • Type: AWS managed policy

  • Creation time: August 06, 2026, 15:27 UTC

  • Edited time: August 06, 2026, 15:27 UTC

  • ARN: arn:aws:iam::aws:policy/AWSTransformNetworkMigrationAgentPolicy

Policy version

Policy version: v1 (default)

The policy's default version is the version that defines the permissions for the policy. When a user or role with the policy makes a request to access an AWS resource, AWS checks the default version of the policy to determine whether to allow the request.
