AWSTransformServerMigrationAgentPolicy

Description: Grants permissions for AWS Transform to perform server migration operations including replication, testing, and cutover using AWS Application Migration Service

AWSTransformServerMigrationAgentPolicy is an AWS managed policy.

Using this policy

You can attach AWSTransformServerMigrationAgentPolicy to your users, groups, and roles.

Policy details

  • Type: AWS managed policy

  • Creation time: August 06, 2026, 15:27 UTC

  • Edited time: September 01, 2026, 10:37 UTC

  • ARN: arn:aws:iam::aws:policy/AWSTransformServerMigrationAgentPolicy

Policy version

Policy version: v2 (default)

The policy's default version is the version that defines the permissions for the policy. When a user or role with the policy makes a request to access an AWS resource, AWS checks the default version of the policy to determine whether to allow the request.
