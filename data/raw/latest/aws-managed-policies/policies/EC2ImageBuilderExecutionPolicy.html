EC2ImageBuilderExecutionPolicy

Description: Grants permissions that allow EC2 Image Builder to call AWS services on your behalf

EC2ImageBuilderExecutionPolicy is an AWS managed policy.

Using this policy

You can attach EC2ImageBuilderExecutionPolicy to your users, groups, and roles.

Policy details

  • Type: AWS managed policy

  • Creation time: June 04, 2026, 17:12 UTC

  • Edited time: June 04, 2026, 17:12 UTC

  • ARN: arn:aws:iam::aws:policy/EC2ImageBuilderExecutionPolicy

Policy version

Policy version: v1 (default)

The policy's default version is the version that defines the permissions for the policy. When a user or role with the policy makes a request to access an AWS resource, AWS checks the default version of the policy to determine whether to allow the request.
